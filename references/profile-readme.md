# Profile README (`<user>/<user>`)

Layout:
1. One-line headline: who you are, what you build.
2. Two-line about: current focus, what you want to be contacted about.
3. Featured projects: 3-6 items. Each: name, one line, link, screenshot.
4. Stack: plain list grouped by area.
5. Contact: only links the user approves.

Rules: no visitor counters, no stat widgets that hit third-party servers unless user asks, no walls of badges. Ask the user for bio facts; do not guess.

Pins: GitHub has no API for pinned repos. Tell the user which 6 to pin by hand.
